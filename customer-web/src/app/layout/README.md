# Layout

Application chrome for LoanEx.

## Structure

| Area | Responsibility |
|------|----------------|
| `shell/` | Global layout composition |
| `navbar/` | Sticky desktop/mobile header |
| `mobile-nav/` | Slide drawer |
| `footer/` | Site footer |
| `breadcrumb/` | Reusable trail |
| `auth-layout/` | Future auth shell |
| `data/` | Local mock data |
| `models/` | Layout TypeScript models |
| `services/` | Signal-based UI state |

No feature pages or business logic live here.
