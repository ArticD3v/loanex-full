# Theme / Animations

## Durations

| Token | Value |
|-------|-------|
| `--lx-duration-fast` | 150ms |
| `--lx-duration-normal` | 250ms |
| `--lx-duration-slow` | 400ms |

## Intent transitions

| Token | Use |
|-------|-----|
| `--lx-transition-hover` | Generic interactive hover |
| `--lx-transition-card` | Card lift / elevation |
| `--lx-transition-button` | Button press / state |

## Animation classes

`.lx-anim-fade-in`, `.lx-anim-fade-up`, `.lx-anim-scale-in`, `.lx-anim-spin`, `.lx-anim-pulse`, `.lx-hover-lift`, `.lx-card-interactive`, `.lx-btn-animated`
