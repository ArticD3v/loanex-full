# Theme / Mixins

Reusable Sass mixins for LoanEx patterns.

| Mixin | Purpose |
|-------|---------|
| `lx-breakpoint-up/down` | Responsive media queries |
| `lx-focus-ring` / `lx-focus-visible` | Accessible focus treatment |
| `lx-truncate` | Single/multi-line ellipsis |
| `lx-visually-hidden` | SR-only content |
| `lx-elevation` | Shadow elevation levels |
| `lx-interactive-card` | Hover lift motion |

Import: `@use 'theme/mixins' as *;` (with `includePaths: ["src"]`).
