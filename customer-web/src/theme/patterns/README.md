# Theme / Patterns

Reusable **visual style patterns** (CSS classes only). No Angular components.

## Catalog

| Pattern | Classes |
|---------|---------|
| Buttons | `.lx-btn`, `.lx-btn--primary\|secondary\|outline\|text\|danger\|success\|icon`, `.is-loading`, `:disabled` |
| Inputs | `.lx-input`, `.lx-input--password`, `.lx-textarea`, `.lx-select`, `.lx-search`, `.lx-otp-input`, `.is-error\|success\|validating\|disabled` |
| Cards | `.lx-card`, `.lx-card--product\|loan\|info\|stats\|review\|interactive` |
| Badges | `.lx-badge--success\|pending\|rejected\|approved\|new\|offer\|emi` |
| Chips | `.lx-chip--category\|brand\|status` |
| Loaders | `.lx-loader-page`, `.lx-loader-section`, `.lx-spinner`, `.lx-btn-loader`, `.lx-skeleton*` |
| Empty | `.lx-empty`, `.lx-empty--products\|orders\|notifications\|emi\|wishlist` |

Use these classes when building shared components or feature UI in later phases.
