# Theme / Utilities

Reusable utility and helper classes prefixed with `lx-`.

## Groups

- **Color / border** — `.lx-bg-*`, `.lx-text-*`, `.lx-border-*`
- **Spacing** — `.lx-p-*`, `.lx-m-*`, `.lx-gap-*` (4–64 scale)
- **Radius** — `.lx-rounded-sm|md|lg|xl|pill`
- **Elevation** — `.lx-shadow-*`, `.lx-elevation-*`
- **Motion** — `.lx-transition-*`, `.lx-anim-*`, `.lx-hover-lift`, `.lx-card-interactive`
- **Helpers** — layout, truncate, divider, container, disabled
- **Responsive** — `.lx-hide-*`, `.lx-show-*`, `.lx-grid-responsive`, `.lx-stack-mobile`

These complement Tailwind; prefer `lx-` tokens when aligning to the LoanEx brand system.
