# Theme / Typography

LoanEx type scale powered by **Plus Jakarta Sans**.

## Scale

| Role | Class | Size |
|------|-------|------|
| Heading 1 | `.lx-h1` | 36px |
| Heading 2 | `.lx-h2` | 30px |
| Heading 3 | `.lx-h3` | 24px |
| Heading 4 | `.lx-h4` | 20px |
| Body Large | `.lx-body-lg` | 18px |
| Body | `.lx-body` | 16px |
| Small Text | `.lx-text-sm` / `.lx-small` | 14px |
| Caption | `.lx-caption` | 12px |

Tokens: `--lx-text-*`, `--lx-font-family`, `--lx-font-weight-*`, `--lx-leading-*`.
